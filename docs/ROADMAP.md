# Roadmap

After the local screening-number MVP works:

- iOS app: lists, call log, notifications (still not a CallKit IVR)
- Optional Call Directory extension to label known spam on the real iPhone line
- SMS filtering
- SIP / Asterisk provider behind `TelephonyProvider`
- Android client using the published OpenAPI
- Family sharing (second user + roles)
- STIR/SHAKEN attestation when a carrier path exists
- CardDAV (Radicale sidecar) for the system Contacts app
- Optional Telegram notify via a local hook (not coupled to a private ops bot)
